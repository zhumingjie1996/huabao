## 常见问题

### 如何把微信云开发的数据导入 App？

1. 在微信云开发控制台导出 `productionList` 和 `operationList` 两个集合的 JSON 文件
2. 把文件传到 iPhone / iPad（AirDrop、微信文件传输、iCloud Drive 均可）
3. 打开 App，首页右上角点「导入」按钮，选择「选择导出文件导入」，两个文件可一次全选
4. 导入按 `_id` 去重，重复导入不会产生重复数据

### 如何备份我的数据？

首页右上角「导入」按钮进入「数据管理」页，点「导出全部数据」，会生成与云开发格式一致的两个 JSON 文件，通过系统分享面板保存到「文件」或发送到电脑。建议定期导出备份。

### 数据存在哪里？会上传吗？

全部数据只存储在您的设备本地，完全离线运行，无任何网络请求，不会上传任何服务器。请妥善保管设备并定期导出备份——卸载 App 会删除全部本地数据，且无法恢复。

### 如何清理旧的操作记录？

进入「记录」页，点左上角垃圾桶图标，可选择全部清除、清除 N 天前、或自定义时间区间清除。清除只影响操作记录，商品数据不受影响。

### App 支持哪些设备？

iPhone 和 iPad，需要 iOS / iPadOS 17 或更高版本。
