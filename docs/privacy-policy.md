# 隐私政策

**生效日期：2026 年 7 月 21 日**
**应用名称：华宝五金**

华宝五金（以下简称「本应用」）尊重并保护用户的隐私。本隐私政策说明本应用的数据处理方式。请在使用本应用前仔细阅读。

## 一、核心结论

**本应用不收集、不存储（在服务器端）、不传输、不分享任何用户数据。**

本应用是一款完全离线的本地工具：

- 无需注册、登录，没有任何账号体系
- 不包含任何网络请求，不会连接任何服务器
- 不包含任何第三方统计、分析、广告 SDK
- 不获取通讯录、相册、定位、麦克风、相机等任何系统权限

## 二、数据的存储

您的全部数据（商品信息、库存数量、价格、操作记录等）仅存储在您自己的设备本地（iPhone / iPad）中，由 iOS 系统的数据保护机制加密保护。

我们无法访问您的任何数据。卸载本应用将同时删除本应用存储在您设备上的全部数据。

## 三、数据的导入与导出

- **导入**：您可以主动选择本地文件（如从微信云开发数据库导出的 JSON 文件）导入到本应用。文件仅在您的设备本地被读取和处理。
- **导出**：您可以主动将数据导出为 JSON 文件，并通过 iOS 系统分享面板自行选择保存或发送方式。导出文件的去向完全由您自己控制。

上述导入、导出操作均由您主动发起，本应用不会在后台自动传输任何文件。

## 四、权限使用说明

本应用仅在使用导入功能时调用系统文件选择器读取您主动选择的文件，不申请任何其他系统权限。

## 五、儿童隐私

本应用不面向儿童收集任何信息，事实上本应用不收集任何人的任何信息。

## 六、隐私政策的变更

如本隐私政策发生变更，我们会在本页面更新并修改生效日期。涉及重大变更时，我们会在应用内作出提示。

## 七、联系我们

如对本隐私政策有任何疑问，可通过 App Store 页面提供的开发者联系方式与我们联系。
